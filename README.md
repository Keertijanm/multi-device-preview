# 📱 Multi Device Preview

A modern developer tool for previewing and comparing webpages across multiple devices on a single screen.

## Overview

Multi Device Preview helps developers, QA engineers, designers, and website owners test responsive websites faster by displaying multiple webpage previews side by side.

Unlike browser DevTools, each preview panel can load a completely different webpage while using different device sizes, making it ideal for UI comparison, regression testing, and responsive validation.

---

## Features

- Preview webpages in Mobile, Tablet, and Desktop modes
- Compare multiple webpages simultaneously
- Display up to 6 independent preview panels
- Configure each panel with its own URL
- Choose device type independently for every panel
- Side-by-side webpage comparison
- Responsive workspace
- Fast switching between layouts
- Designed for developers, QA engineers, and designers
